How to use this

    
    
      
  1. Open this file by double-clicking it — it runs entirely in your browser, no install needed.
    2. 
      
  2. In the ERP, export the Daily Sales Detail / Segment Wise report as CSV or Excel (instead of PDF) and save it to your device.
    3. 
      
  3. Click the upload box and pick that CSV/Excel file. Branch and Date are filled in automatically from the file — edit them if you'd like something different.
    4. 
      
  4. The tool reads every row and groups it into Dine In, Take Away and Delivery — adding together every matching row (so if there are 2 Dine In rows, both get summed; 3 Take Away rows, all 3 get summed) — using the Net Sales and Cheque columns.
    5. 
      
  5. Pick one of the 4 image styles, then tap Download as image to save a PNG ready to share — or use Copy message for a plain WhatsApp text version.
    6. 
    

    
Everything happens locally in your browser — the file is never uploaded anywhere.
