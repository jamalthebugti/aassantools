Rider Fuel Adjustment

Select riders, count orders and calculate fuel automatically

1. Upload Files

Required. Upload the order list containing all rider orders.
Optional. Upload your rider/fuel template if you want to use its rider list and preserve its Excel design.


2. Choose Riders

Select only the riders you want to include in the final Fuel Adjustment.

Calculation:
No. of Orders × Fuel Rate = Order Amount
Total Amount = Order Amount + Other Amount + Grave Yard Amount

If a rider ID exists, it will appear only in the ID column.
