Daily Summary Report Generator

Uses the same file-reading and extraction engine as the Daily Sales Segment Calculator, presented as a concise WhatsApp-ready management summary.

Before you rely on this: Gross Sales, Discount, Net Sales, and the Dine-In / Delivery / Takeaway breakdown use the exact same proven column-detection technique as the Sales Segment Calculator, tested against your real export. Food Cost, Refunds, Dispatch Time, Dine-In Feedback, and Delivery Complaints are not part of that report's file structure — I've never seen a sample file containing them, so this tool does a best-effort search for those labels and pre-fills them if found, but every one of those fields stays fully editable so you can correct or fill it in by hand. Send me a real sample of that fuller report and I'll calibrate exact extraction for those fields too.
